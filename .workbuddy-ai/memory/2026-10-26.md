## 睇片排查工具鏈（微信 mp4）

```

"$FF" -i in.mp4 -vf "fps=2,scale=540:-1" out/f_%02d.png       # 抽幀

"$FF" -i in.mp4 -vf "eq=contrast=2.2:brightness=-0.12" ...    # 反眩光（手機拍平板必用）
```
