## Native Android Print Agent（取代 Tunnel / 自管證書，方案 A 完全取代）

- native bridge 係 **同步 call + 異步 callback** 模式：`printJob()` 同步回 `{ok,queued}`，真正打印完 Kotlin `evalJs("window.__posNativePrintResult(json)")`；POS 側 Promise 等 callback（8s timeout，超時當 queued ok）
- 完全取代 = 只有 Android 裝置能打印；非 Android（desktop/iPad）冇 `window.PosNative` → fallback HTTP bridge（如有設 URL），否則 job 維持 pending
- Salon + 餐飲共用同一 native dispatch 路徑（`dispatch.ts` + `salon/print.ts` 都 call `dispatchJobToNative`）
