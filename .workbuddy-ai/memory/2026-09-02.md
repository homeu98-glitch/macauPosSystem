### Supabase Realtime 限制（查證 supabase.com/docs/guides/realtime/limits）

- **postgres_changes payload 上限 1,024 KB；超標時 `new`/`old` 只帶每個 ≤64 bytes 嘅欄位** → `template`/`items`/`content` 會被剝走。
- Broadcast payload：Free 256 KB / Pro 3,000 KB。Concurrent connections：Free 200 / Pro 500。Messages/s：Free 100 / Pro 500。Channels per connection 100。
- **⇒ 關鍵設計：Realtime INSERT 事件只當「叫醒訊號」，權威拎單一定要經 `pos_claim_print_jobs()` RPC 由 DB 直接攞完整 row。** 順便一併解決 event 遺失同多機爭奪。

### 方案要點（詳見 docs/96）

- 原子拎單：`pos_claim_print_jobs()` PL/pgSQL，`for update skip locked` + `attempts < 5` + `ttl > now()` → **物理上唔可能重複打印**。
- migration 0020：`pos_print_jobs` 加 `printer/kind/store_name/payment_method/total/qr/qr_url/copies/ttl/updated_at/claimed_by/claimed_at/attempts/last_error/finished_at`；新增 `pos_print_agents`（只存 `token_hash`）。
- 4 條 Vercel route（service_role）：`pair` / `claim` / `result` / `heartbeat`。
- 配對：APK 顯示 `agentId` QR → iPad 掃（復用 `loadJsQr()`）→ server 簽 token → 經 **broadcast 頻道 `pair:<agentId>`** 推畀 APK（一次性、唔落 anon 可讀表）→ APK 存 EncryptedSharedPreferences。**Sunmi 唔使有相機。**
- 狀態機：`pending → printing → sent|failed`，`failed` 且 `attempts<5` 自動退回 `pending`。

### 配對流程改咗做法（偏離 docs/96 初版）

- **刻意唔解析 payload**：任何喺 topic 上面嘅 event 都當叫醒訊號（>1MB 會被截斷，解析只會引入 bug）。

## 16:1x · 修 relay 面板喺原生殼內顯示（用戶實測發現）

用戶喺 macau-pos 開「打印機頁面」見到 relay 配對卡，呢個唔應該出現（relay UI 只應喺純 website / PWA）。根因：`RelayPairingPanel` 當初掛 `device-settings` 時冇加 `isRunningInNativeShell()` gate（prior session 已知省略）。

**查證**（決定點解可以咁 gate）：`print-agent-android/MainActivity.kt` 喺 POS 終端模式（`relayHome=false`）會 `addJavascriptInterface(Bridge(), "PosNative")`（L99）再 `loadUrl` → `window.PosNative.printJob` 存在 → `isRunningInNativeShell()` 喺 APK WebView 返 `true`；`relayHome=true` 模式則直接 `startActivity(RelayActivity)` 而家無 WebView。PC Companion 經 `companionShell` 同樣返 `true`。`isRunningInNativeShell()` 有 `typeof window` 守護，SSR-safe。

**修法**：`relay-pairing-panel.tsx` 加 `const [nativeShell] = useState(() => isRunningInNativeShell());` + `if (nativeShell) return null;`（mirror `login-screen.tsx` 慣例）。順便慳咗原生殼內無謂嘅 `/pair-status` 探測。`tsc --noEmit` 過（剩 known `LayoutProps` 誤報）。MEMORY.md 通道優先級條已同步「已 self-gate」。
