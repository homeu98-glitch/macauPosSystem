## 訂單頁「成個頁面被拉動」＝ iOS 文件層橡皮筋（非 layout bug）

**症狀**（J 21:29 實機影片，iPad 橫向）：喺訂單頁右邊「店內線下訂單」列表用手指拖，
**成個畫面**（連左側欄、`訂單` 標題列）一齊上落，放手彈返原位（t=5s 復原）。

**診斷**：
- 睇影片抽格（imageio-ffmpeg，`pip install imageio-ffmpeg` 落 managed venv）確認係「拖→位移→放手彈返」，
  唔係真 scroll（真 scroll 唔會自動返原位）。
- `layout.tsx` `body` 已經 `h-full overflow-hidden`，`orders-hub` 外層 `h-[100dvh] overflow-hidden`
  ⇒ document 根本冇 scrollTop（headless 實測 `docScrollable = 0`）。
  ⇒ 呢個係 iOS WebView 對**文件層**嘅 overscroll bounce，唔關任何 div 事。

**改法**（`src/app/globals.css`，純 CSS，零 layout 影響）：
1. `html, body { overscroll-behavior: none; }` —— 截斷文件層 bounce／pull-to-refresh。
2. `.overflow-auto / .overflow-y-auto / .overflow-x-auto / .overflow-scroll { overscroll-behavior: contain; }`
   —— 列表拖到頂／底之後唔好把剩餘手勢「傳染」去文件層（否則一樣成頁彈）。
   呢段係 unlayered 規則，會蓋過 utilities layer 嘅 `overscroll-auto`，日後新滾動區自動覆蓋。

**驗證**：dev server 3019 + puppeteer 讀 computed style → `html/body = none/none`、
滾動容器 = `contain`、`docScrollable = 0`。

**未確認**：iPadOS < 16 會忽略 `overscroll-behavior`（要 iNoBounce 式 touchmove 攔截）。
如 J 實測仍然彈，下一步 = 加 `touchmove` non-passive guard（注意會拖慢慣性滾動，最後手段）。

## 訂單頁 header：兩粒接單掣要和標題同一行（iPad 半欄）

**症狀**：`orders-hub` 左右分欄後，iPad（1080）每欄 header 行寬只有 **472px**，
而「標題塊（195）＋ 兩粒接單掣（288／312）」＝ 499／529px ⇒ `flex-wrap` 把控件擠落第二行，
變成「標題／接單掣／chips」**三行**。桌面 1440 行寬 652 ⇒ 499 塞得落 ⇒ 一行過（所以只在 iPad 出事）。

**修法（兩個槓桿，都係 CSS，冇 JS）**：
1. 標題塊（cards）加 `lg:basis-0 lg:grow` ⇒ 可以被壓縮，唔會再把控件擠落下一行。
   加 `lg:` 係為咗手機（<1024 疊成單欄）維持原狀（標題一行、控件自己一行）。
2. header 加 `@container`；`MerchantOpenPill` / `AutoAcceptPill` 嘅 **md** 尺寸加
   `@max-[540px]:` 變體（收 padding、label 12→11px、掣面 16→12px，**高度不變**）
   ⇒ 窄容器自動收緊、闊容器（桌面）**像素不變**。
   - 540 嘅來源：md 兩粒掣最闊要 529px 行寬（右卡「線下接單＋自動接自助單」）。

**實測**（puppeteer，`emulateMediaFeatures pointer` 新版 CDP 已唔支援，唔好用）：
1080／1140／1194 三種寬度都係同一行，header 高度 148 → **88px**（慳 60px 畀列表）；
1440 控件闊度仍然 288（零改動）；390 手機行為不變。
截圖：`docs/mockups/orders-header-single-row-2026-10-25/`。
驗證：`tsc` 0、eslint 0、`node --test` 2657 pass、`next build` 成功。

**🔴 踩過嘅坑**：`button, input { font: inherit }`（globals.css，unlayered）會蓋過
寫喺 `<button>` 身上嘅 `text-xs` ⇒ 掣面字級實際係 **16px**（繼承 body）。
所以要縮掣面字，一定要包一層 `<span>` 再落字級（`xs` 原本已係咁做，今次 md 都要）。
