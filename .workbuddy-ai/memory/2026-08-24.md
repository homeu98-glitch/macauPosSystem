### winCodeSign symlink error 深入診斷（續）
- 錯誤本質：electron-builder 自帶 `7zip-bin/win/x64/7za.exe` 解 `winCodeSign-2.6.0.7z` 時，檔案內 `darwin/10.12/lib/{libcrypto,libssl}.dylib` 兩條 **macOS symlink** 喺非提權 Windows 建唔到 → `用戶端沒有這項特殊權限` → exit 2 → retry 4 次 abort。呢兩條 symlink 喺 Windows 完全冇用，純粹係 privilege 問題。
- **winCodeSign 係 Windows build 無條件 fetch**（唔係只有簽名先拉）：`getBin("winCodeSign")` 唯一入口，caller 得 `getToolPath`（簽名用）/ AppxTarget / winPackager 非 win32 rcedit 分支；喺 win32+nsis 下得 `getToolPath`，但 7za 喺「要唔要 signtool」之前就掛，所以 env bypass 救唔到。
- 試過 `SIGNTOOL_PATH`（指向 cache 入面已完整 extract 嘅 `extracted_clean/windows-10/x64/signtool.exe`）+ `CSC_IDENTITY_AUTO_DISCOVERY=false`，都救唔到——`getToolPath` 有 `if (process.env.SIGNTOOL_PATH) return early` 短路，但 electron-builder 子進程好似收唔到呢個 env（build 照樣 download winCodeSign）。
- **確認 build 係 unsigned**：`CERTS_COUNT=0`（store 無 code-signing cert）、`package.json` 無 cert config、`cscInfo` lazy 解析喺無 `WIN_CSC_LINK`/cert 時返 null → 出嚟嘅 exe 唔會簽名（Windows SmartScreen 會 warn，本地/測試 OK）。
- **結論（唯一可靠 fix）**：開 **Developer Mode**（Settings → Privacy & security → For developers → Developer Mode，一次性，之後普通 terminal 都有 symlink 權限）**或** terminal **Run as administrator** → 7za 建到嗰兩條 symlink → build 過。沙盒本身冇提權，所以無論如何要喺用家 Windows dev box 做。
- cache 雜物：`%LOCALAPPDATA%/electron-builder/Cache/winCodeSign/` 有成 16 個失敗 retry 留低嘅 `<random>.7z` + 空 temp 夾；`extracted_clean/` 係已完整 extract 嘅 winCodeSign（可留）。
