## 線下訂單排序改「單號由小到大」（用戶反映：改狀態後單會移位）
- **根因**：兩處排序都用 `orderTimestamp()`（`updatedAt`）做 key：
  - `src/lib/pos-order-filters.ts` `filterQuickActionBarOrders()` → 收銀「線下訂單」strip
  - `src/components/local-orders-panel.tsx` `filteredOrders` → /orders 線下訂單卡
  每次改狀態（出餐 / 可取餐 / 結帳）都 refresh `updatedAt` → 張單彈去最前 = 「按狀態排」。
  另 `pos-app.tsx` `counterKioskOrders`（堂食模式「自取 / 掃碼訂單」面板）本身冇 sort，直接繼承 `openOrders`（`mergeOrderLists` = updatedAt 新→舊）→ 一樣會移位。
- **新真源 `compareOrderByLocalNo()`（`src/lib/pos-order-filters.ts`）**：
  1. `localOrderNoSortKey()` 用 `/^(\D*?)(\d+)$/` 拆 `(prefix, numeric)`。prefix 只認純非數字 → fallback 單號（`自取-a1b2c3`）當「冇號碼」，避免誤抽尾數。
  2. 排序 key 順序：**numeric ascending → `createdAt` ascending → prefix localeCompare → id**。
  3. 有號碼排先過冇號碼（舊單 / fallback 靠 createdAt 排尾）。
  - 點解要 createdAt 做副 key：序號係 per `(store_id, kind, biz_date)` 各自遞增（migration 0012），跨 prefix 號碼會撞（`自取01` 同 `外賣01` 同一日並存）→ 撞號碼時按下單時間分先後（呼應用家「跨 prefix 按下單時間」）。
- **改 3 個顯示位 + 1 個 strip 結構**：
  1. `filterQuickActionBarOrders()` → `.sort(compareOrderByLocalNo)`
  2. `local-orders-panel.tsx` `filteredOrders` → `.sort(compareOrderByLocalNo)`（順便由 import 移除已唔用嘅 `orderTimestamp`）
  3. `pos-app.tsx` `counterKioskOrders` → 加 `.sort(compareOrderByLocalNo)`
  4. **`quick-local-orders-strip.tsx` 改單一列**：原本 render 兩段（`preparingOrders.map` → `waitingOrders.map`），單一撳「可取餐」就由左段彈去右段 —— 呢個本身就係「按狀態分段」。現改成 `cards = [...preparing, ...waiting].sort(compareOrderByLocalNo)` 單一列 render，每張卡嘅 `mode`（藥丸配色 + 掣）由單自己嘅狀態決定，同分段時完全一致。
