## Vercel build 失敗 → 修復（online-orders.tsx 折扣欄位未提交）
- **現象**：Vercel 部署 `4845489`（`main`）`next build` 失敗，`src/components/online-orders.tsx(966-977)` 報 `Property 'discountRate'/'discountAvos' does not exist on type '{ name: string; qty: number }'`。
- **根因**：`online-orders.tsx:79` 嘅 `detailItems` state 原本型別係 `Array<{ name: string; qty: number }>`，後來本地加了 `discountRate?`/`discountAvos?` 同埋 `openOrderDetail` 入面 map 埋兩個 field（用嚟喺訂單明細位顯示「折扣多少」）—— **但呢個 fix 一直未 commit**，Vercel 用舊 `HEAD` build 就爆 type error。
- **修復**：`git add` + commit `1748b5d`（3 file：`online-orders.tsx` + `quick-online-orders-panel.tsx` + `src/lib/pos/sync-flush.ts`，全部本地已改未提交、type-check 乾淨）；`git push origin main` → `4845489..1748b5d`。Vercel 會自動用新 commit rebuild。
- **教訓**：本地改完會令 `tsc --noEmit` 過嘅 code，如果未 commit/push，Vercel 永遠用舊 `HEAD` build → 一樣爆。每次修完 type error 一定要 push 先算數。
- **CSS warning（唔致命）**：`globals.css` 有條 `@media (min-width:某寬)` 無效 media query（Tailwind 生成嘅 placeholder class `min-[某寬]:flex-nowrap` 殘留），只係 warning 唔阻 build；同用戶確認過唔理。
