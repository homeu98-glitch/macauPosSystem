## 線上訂單兩項修復

### 問題 1：自動接單關閉後仍接單

**根因**：`device-settings.tsx` mount-time fetch 嘅 merge 邏輯 `localAutoAccept || serverAutoAccept` 有 bug。用戶關閉 autoAccept（本地 false）→ POST 失敗或 server 延遲 → server 返回舊值 true → OR 邏輯 false || true = true → autoAccept 被靜默重置為 true。

**修復**：
- `device-settings.tsx` L263-278：改為 local-only 邏輯。本地值係權威，server 值只在「本地從未改過」時補漏。本地 false 永遠不被 server true 覆蓋。
- `online-orders.tsx` L601-614：toggle POST 加 `.catch()` + console.warn
- `pos-app.tsx` L3708-3724：快餐模式 toggle 同樣修復

### 問題 2：線上訂單打印未產生 Print Center entry

**根因**：`pos-app.tsx` 嘅 `onPrintJobUpsert` Realtime callback 用 React state `current` 做 `savePrintJobs` 基底。`bridgeLedgerOrderToPos` / `printKitchenForLedgerOrder` 直接 `savePrintJobs` 寫 localStorage 但唔更新 React state。下次 Realtime push 觸發 `onPrintJobUpsert` 時，`savePrintJobs(current)` 用過時 React state 覆蓋 localStorage，沖走線上訂單嘅 print jobs。

**修復**：
- `pos-app.tsx` `onPrintJobUpsert`：改用 `loadPrintJobs()` 做基底而唔係 React state `current`
- `pos-app.tsx` `persistPrintJobs`：加 `pos-print-jobs-changed` event dispatch（令 Print Center 即時刷新）
- `pos-app.tsx` `printReceipt`：加 event dispatch + console.warn 當冇 receipt printer
- `ledger-pos-bridge.ts` `bridgeLedgerOrderToPos` + `printKitchenForLedgerOrder`：改用 `mergePrintJobs` 統一合併邏輯（唔再用 spread）
- `print-jobs.ts` `appendPrintJobs`：同樣改用 `mergePrintJobs`

### tsc 驗證
- `npx tsc --noEmit` 零新 error（只有已知 `layout.tsx` LayoutProps 誤報）
