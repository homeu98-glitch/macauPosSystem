# 2026-08-20 工作記錄

## Native Print Agent APK Build 成功

沙盒環境原來有 Android Studio JBR（Java 21）+ Android SDK 36 + build-tools，成功 build 出 debug APK。

### Build 過程中 fix 嘅 3 個問題

1. **Kotlin plugin 衝突**：AGP 9.2.1 已內建 Kotlin 支援，再加 `org.jetbrains.kotlin.android` plugin 會報 `Cannot add extension with name 'kotlin', as there is an extension already registered`。Fix：`build.gradle.kts`（root + app）移除 `id("org.jetbrains.kotlin.android")`，只留 `id("com.android.application")`。
2. **kotlinOptions deprecation**：AGP 9.x 廢棄咗 `kotlinOptions { jvmTarget = "11" }`。Fix：改用 `kotlin { compilerOptions { jvmTarget.set(JvmTarget.JVM_11) } }`。
3. **Variable shadowing**：`MainActivity.kt` `printJob` 方法入面 local `val printer = ...PrinterCfgDto...` 遮蔽咗 class-level `private val printer = EscPosPrinter()`，令 `printer.printRaw()` unresolved。Fix：class field 改名 `escPosPrinter`。

### Build 結果

- APK 路徑：`print-agent-android/app/build/outputs/apk/debug/app-debug.apk`
- 大細：2.6MB
- 淨係 3 個 deprecation warning（databaseEnabled / onBackPressed），唔影響功能
- 用 `JAVA_HOME="/c/Program Files/Android/Android Studio/jbr"` + `local.properties` 寫 `sdk.dir`

## Hub 配對 UI 實測調試（用戶報 bug）

用戶喺 POS 測試 Hub 配對，報：① 開 Hub 設定頁 → `{"ok":false,"error":"not found"}`；② 掃描區網掃唔到嘢；③ 手動加打印機唔得。

### 攞返 `pos-printer-android` 真實 source 對齊（repo: ericchang1015/pos-printer-android）
- `LanHttpServer.kt`：routes 全部齊（`/api/status` GET、`/api/scan` GET+POST、`/api/manual/assign/remove/clear` POST、`/api/print` GET+POST、`/beacon.png`、`/setup.html` GET → asset）。
- **CORS 全開**：`Access-Control-Allow-Origin: *` + `Access-Control-Allow-Private-Network: true` → HTTPS POS 嘅 `fetch` 去 HTTP Hub 唔會被 mixed content / PNA block（呢點確認過，唔係問題）。
- `PrinterHub.requestScan(prefix, identify)`：**`prefix` 必須 match `\d{1,3}\.\d{1,3}\.\d{1,3}`（IP 頭 3 段網段），否則直接 return false 唔掃描**。`prefix` 係由 caller 傳，`/api/status` 回 `subnetPrefix` 俾 caller 用。

### 確定 bug + fix
- **scan 傳空 prefix**：舊 `startHubScan()` 傳 `prefix:""` → Hub 永遠唔掃描 → 掃唔到嘢。Fix：`hub.ts` 嘅 `startHubScan(prefix?)` 冇 prefix 就先 `fetchHubStatus()` 拎 `subnetPrefix` 用；`device-settings.tsx` 加咗「掃描網段」輸入框（預填 `subnetPrefix`，可 override），`handleStartScan` 傳 `hubSubnetInput`。
- `tsc --noEmit` 通（只餘 `layout.tsx` LayoutProps 預存誤報）。

### 仲未解 / 要跟進
- **`/setup.html` 回 not found**：同事隻 Hub APK 大概率冇 bundle `setup.html`（或 build 同 repo main 唔同）。呢個係 APK 嗰邊嘅問題，POS 改唔到。核心 scan/manual/assign 已做落 POS 入面，唔使靠 Hub 嘅 setup.html。已經同用戶講：scan/manual 先試，setup 頁睇同事 APK。
