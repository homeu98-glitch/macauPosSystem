## 修 `npm run build` 6 個 TS 錯誤（Vercel build 失敗）

用戶貼咗 Vercel build log（Next 16.3 Turbopack，commit f0f056e，Cleveland cle1），`next build` 喺 type-check 階段 6 錯全喺 `order/page.tsx` 退場。4 個唔同根因，已修：

- `src/lib/pos/use-pos-realtime.ts`：`PosRealtimeHandlers.onOrderUpsert` 改 optional（`onOrderUpsert?`），subscribe body 改 `?.` call。原因：kiosk 頁只傳 `onSoldoutUpsert`，舊 required 宣告觸 TS2345。
- `src/app/order/page.tsx`：`pushLine(...)` 兩個 call site（addItem line~272、spec-modal add line~594）移除 `quantity: 1`（函數內部已 set quantity:1，傳入違 `Omit<CartLine,"lineId"|"quantity">`）。修 TS2353 ×2。
- `src/app/order/page.tsx`：`SpecDraft.specs` 由 `OrderItem["selectedSpecs"]`（optional）改 `NonNullable<OrderItem["selectedSpecs"]>`（必填陣列）；規格彈窗 `nextSpecs` 註解同步改 NonNullable。修 `.find`/`.filter` possibly-undefined TS18048 ×3（line 542/547/588）。

**驗證**：sandbox 跑 `tsc --noEmit -p tsconfig.json`，6 個 kiosk 錯全部消失，只剩 `layout.tsx(37) Cannot find name 'LayoutProps'` 呢個**已知誤報**——`LayoutProps` 係 Next 16 `next-types-plugin` build 時生成入 `.next/types` 嘅 global 型，standalone tsc 見唔到（`.next/types` 未生成），但 `next build` 先生成再 type-check，所以 Vercel log 先冇報佢。結論：`next build` 應已過。
