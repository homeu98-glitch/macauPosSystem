## 0007 SQL 語法錯誤修復（用戶 Supabase 執行報 42601）

用戶喺 Supabase SQL Editor 貼 0007 執行報 `ERROR: 42601: syntax error at or near "end"`（LINE 61）。
原因：`end` 係 PostgreSQL 保留字，唔可以裸用作欄名。

修復（重命名保留字欄，唔影響前端 camelCase 字段）：
- `salon_staff_leaves`：`end text` → `end_date text`（start 非保留字，保留 `start`）
- `salon_staff_shifts`：`end text` → `end_time text`（start → `start_time` 一併改齊風格）
- 同步更新版頭註釋：指明 sync route 已擴充（見下）。
