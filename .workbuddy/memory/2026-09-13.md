### 根因（真兇，唔係我上一輪嘅改動）

```tsx
const dateSelection = { key: dateFilter, custom: customRange };  // ❌ 每次 render 新 ref
```
＋兩個子元件都係「`useMemo([dateFilter,…])` → `useEffect([filteredOrders])` → 父層 `setState`」：

4. 父 re-render → 返 1 🔁

⚠️ `useEffect` 內 `setState` **唔會**觸發 React「Too many re-renders」→ 唔 throw，
