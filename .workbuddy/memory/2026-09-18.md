### 推翻上一個結論：**唔係時序問題，係程式碼本身有兩條路都斷**

### 根因 (a)：`reopenPosOrder()` **從不推播同步事件**
`src/lib/pos-orders.ts:203-217`（修復前）：
```ts
saveOrders(next);                                   // 只寫本機 localStorage
if (isPrintContentEnabled("reopen")) { appendPrintJobs(...); }
window.dispatchEvent(new CustomEvent("pos-orders-changed"));  // 只通知同機 React

```
**兩個動作都唔會離開呢部機** ⇒ 雲端 `pos_orders` 永遠停留返結前狀態。

🔑 對照：`cancelLocalOrder`（:344-355）同 `rejectSelfOrder`（:393-404）**兩者都有**
```ts
saveQueue(enqueueEvents(loadQueue(), withStoreScope([event])));
notifyQueueChanged();
```
⇒ 返結係**唯一漏咗推播**嘅狀態轉換（結構性遺漏）。
