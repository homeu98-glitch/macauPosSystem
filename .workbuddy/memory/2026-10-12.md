## 交班彈窗「按鍵很難按」診斷（用戶片：18.9s iPad 實拍，1136x640）

- 影片時間線（CDP 逐幀，每 0.5s）：t0–1「結數交班·核對金額」彈窗→撳下一步→t2–4「二次確認」彈窗（手指指住「18 筆無歸組資料」警告，藍圈＝iOS 文字放大鏡）→t5 回主頁撳黑色「結數交班並打印」→**t6–8 彈窗再開＋軟鍵盤彈起，遮蓋底部「取消／下一步」**→t13–15 再次鍵盤遮擋→t16 之後先撳鍵盤收起鍵先撳到下一步。
- 根因：`shift-page.tsx:2581` 現金差額 input 有 `autoFocus`。iPad 橫向 1136×640，軟鍵盤約 300px 高；ResponsiveModal 面板置中（max-h calc(100dvh-16px)），action bar 在面板底部（y≈570–624）→ **每次開彈窗都被鍵盤完全遮蓋**，必先收鍵盤先撳到下一步。ios-focus-helper 只幫「輸入框入鏡」，救唔到 action bar。
- 幫兇：① 彈窗按鈕 `px-4 py-2 text-sm`≈36px，細過全庫通用 `min-h-[40px]`/`min-h-11` 慣例（date-range-filter-chips／inventory-table 等都係）；② ResponsiveModal overlay `onClick={onClose}`（allowPointerEventsOnOverlay 默認 true）→ 細按鈕撳歪少少直接關彈窗→重開→autoFocus 再彈鍵盤，形成片中死循環。
- 其他 autoFocus 屬「刻意要彈鍵盤」（備註輸入、菜品名稱必填欄）唔同病；交班個案特殊在於該欄**選填**（「有落差先填」），無理由自動取焦。
- 提案（等 J 拍板，未落手）：① 刪 `shift-page.tsx:2581` autoFocus（加註解）；② 交班三步彈窗 action 按鈕＋主頁「結數交班並打印」升 `min-h-11 px-5`；③（可選）交班彈窗 `allowPointerEventsOnOverlay={false}` 防掂誤關，或 ResponsiveModal 加 visualViewport 守衛令 action bar 避開鍵盤。
- 工具教訓（重複中招）：CDP 靜態 server 必須按副檔名回 content-type——`.html` 回 `image/png` 會令 Chrome 將頁面當圖片解析、DOM 全空、截圖全黑（contact sheet + zoom 各中一次）；最穩係改 `file://` 直載圖片零伺服器。另 `Page.captureScreenshot` clip scale>1 要配 `captureBeyondViewport:true`，否則攞到全黑。
