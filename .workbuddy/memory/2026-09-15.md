## 修 0040 SQL 錯誤 + 補上 PIN hash 程式碼（用戶實跑回報）

### 根因（重要教訓，會再中）
🔴 `:'pepper'` 係 **psql CLI 專屬嘅變數插值語法**（要 `psql -v pepper=...`）。
**Supabase SQL Editor 唔係 psql**，唔支援 ⇒ 語法錯誤。
⇒ **本專案所有 migration 一律唔可以用 psql 專屬語法**（`:'var'`、`\set`、`\i`、`\copy`）。
改用 **PL/pgSQL 變數 + 守衛**：`do $$ declare v_pepper text := '<<<PEPPER>>>'; ... if v_pepper='<<<PEPPER>>>' then raise exception ...` ⇒ 唔記得換就大聲失敗，唔會靜默寫錯 hash。

原本三步上線嘅 **②「部署改用 pin_hash 的新碼」我從來冇寫**。⇒ 用戶就算 SQL 跑成功都**零安全提升**（明文照用）。
