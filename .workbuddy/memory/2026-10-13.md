# 2026-10-13

## 報表「貨品細項」計埋未付款收據（J bug 報告）→ 已修

- 根因：`buildPurchaseSummary()`（`src/lib/inventory-stats.ts`）將**全部**收據（paid+unpaid）餵入 `buildItemStats()` ⇒ 貨品細項排行／合計包含未付款收據。
- 修法（J 口徑）：細項排行 `items`／`itemsTotal` 及新欄位 `itemsPaidTotal` 只計 `payment_status === "paid"`；KPI 三格（total/paid/unpaid）、供貨商／付款方式分佈／月度支出**照舊計全部**（unpaid 係刻意獨立顯示）。
- ⚠️ `itemsPaidTotal`（Σ品項單價×數量，只計 paid）≠ `paid`（收據 total_amount 加總）≠ `total`。UI 兩個「合計」行（買貨明細卡細項表＋貨品細項彈窗）改用 `itemsPaidTotal`。
- UI 加註「只計已付款收據」（彈窗副標＋卡腳註）；新 i18n key `只計已付款收據`（zh+en 兩字典都加）。
- 守衛：`inventory-contract-guard.test.ts` 新增「貨品細項只計已付款」測試（regex 守 buildItemStats(paidReceipts) + 兩個合計行用 itemsPaidTotal）。146 tests pass。
- 附帶口徑：`normalizePaymentStatus("")` 回 "unpaid" ⇒ 舊收據冇記付款狀態會當 unpaid 唔入細項（同 KPI 口徑一致）。
- 庫存頁（`inventory-view.tsx` 用同一 `buildPurchaseSummary`）自動同步新口徑。
