# 2026-09-11

## 報表 KPI 帶「5 格一行 + 5 格全寬堆疊」根因診斷 + 修正（已修）
- 用戶回報：報表頁最上方 KPI 只有頭 5 格正常一行；尾 5 格（未結帳訂單／餘額總額／會員充值／會員扣點／毛利（估））各自佔滿一行、**緊貼無 gap**。與 2026-09-10 交付時描述嘅「10 格 → 5-5」不符。
- 根因：`src/components/restaurant-daily-report.tsx`
  - L2199 開 `<div className="mb-4 grid grid-cols-5 gap-3">`
  - L2243 **提早出現 `</div>`** → 個 grid 喺第 5 格之後就閂咗
  - L2250–2337 嘅其餘 5 個 `<Kpi>` 掉出 grid，成為 L2115 `div.block.p-4` 嘅直接子元素 → 全寬堆疊，`gap-3` / `mb-4` 亦隨 grid 消失
- 成因（2026-09-10 合併 grid 嘅操作失誤）：合併「兩個 5 格 grid」成「一個 10 格 grid」時，刪走咗第二個 grid 嘅 `<div>` 開頭同結尾，但**漏刪第一個 grid 嘅 `</div>`**。
- 為何驗證全綠卻漏咗：JSX 仍然完全平衡（`<div>` 有閂、`</>` 有閂）→ typecheck / eslint / next build 全部 0 error，`npm run test` 亦冇 DOM 測試。**只有肉眼睇畫面才捉到。**
- 建議修正（待用戶確認）：刪 L2243 嗰個 `</div>`，令 10 個 `<Kpi>` 同處一個 `grid grid-cols-5`。同時修好 L2245–2249 嗰段「同上面係同一個 grid」嘅誤導註解。
- 已寫入 `docs/113-agent-gotchas.md` 新章節「JSX 合併 grid 漏刪 `</div>`：build 全綠但版面散」。
- 用戶偏好提醒：呢個頁面嘅版面改動，用戶要求「**畫給我看，我說動手才動手**」→ 先出模擬圖 + 診斷，**唔好直接改**。
