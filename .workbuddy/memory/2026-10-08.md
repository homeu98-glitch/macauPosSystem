### 🔴 三個 codemod 嘅關鍵設計
1. **JsxText 逐個包係安全嘅** —— Babel 嘅 JSX 文字正規化（`cleanJSXElementLiteralChild`）
   係**決定性**嘅，所以 `{t(渲染後文字)}` 同原本 render **byte 完全一樣**。
   （`jsxRenderedText()` 就係照抄 Babel 嗰段。）
2. **`on[A-Z]` 屬性排除只可以喺 `sink === "jsx"` 時生效**：toast 文案住喺 `onClick`
   handler 入面，一律排除會靜靜漏 ~100 條。要回傳 sink **種類**（`"prop"/"func"/"jsx"`）。
3. **一定要爬過透明包裝層**（`ConditionalExpression` / 邏輯運算 / `as` / 括號）先判斷 sink，
   否則漏 `setToast({ message: cond ? "a" : "b" })`（實測漏 20 處，112 → 136 包）。
   ⚠️ `ts.isLogicalExpression` 喺呢個 TS 版本**唔存在**，要用
   `ts.isBinaryExpression(p) && LOGICAL_OPS.has(p.operatorToken.kind)`。

### 🔴 `tRef` pattern（mount-only effect）
`t` 係 `useCallback([lang])` ⇒ 切語言時係**另一個 function**。喺 `useEffect(…, [])` 用 `t`：
加 `t` 落 deps = 每次切語言重跑 mount effect；唔加 = `exhaustive-deps` 警告 + 攞到舊語言。

```tsx
const tRef = useRef(t);
useEffect(() => { tRef.current = t; }, [t]);
```

### 🔴 今次最重要嘅新發現：「已填值字串」永遠命中唔到字典
`orderCodeLabel(order)` 回 `取餐碼 005`（**已填值**），但字典 key 係 `取餐碼 {code}`
