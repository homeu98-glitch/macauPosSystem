### 關鍵設計決定（唔好改錯）

1. **每平台最多一個 active** 用 **partial unique index**（`unique (platform) where is_active`）
   DB 層強制，唔靠應用層自律。切換走 RPC 一個 transaction（先落閘、後上位），
   唔可以喺 route 分兩條 update —— 中間失敗會撞 index 或者留低「一個 active 都冇」。
2. **公開 API 只回 5 個欄位**（platform / version / downloadUrl / fileSize / notes），
   表本身 revoke 咗 anon。唔可以為方便而 grant anon select。
3. 🔴 **base URL 唔可以 fallback 去 `NEXT_PUBLIC_SUPABASE_URL`** —— 嗰個係 **Ledger** 專案，
   Storage 冇 `macauposapk`。Fallback 過去會派一條 **404** 連結，而 `<a href>` 404
   只係瀏覽器錯誤頁，**任何 log 都見唔到**。優先次序：
   `RELEASE_DOWNLOAD_BASE_URL` → `SUPABASE_URL` → `NEXT_PUBLIC_POS_SUPABASE_URL` → `null`。
4. **DTO 要分開 `downloadUrl`（解析後）同 `explicitDownloadUrl`（DB 原值）**：
   admin 編輯表單用後者。用前者會把「由 `file_path` 砌」變成「寫死一條完整 URL」，
   之後換網域就唔會跟住變。**呢個係驗證時實際踩到嘅坑**（已加測試釘死）。
5. **裝置偵測喺 `useEffect` 做**，唔可以攞嚟做 `useState` 初始值 ——
   SSR 冇 `navigator`，初始值一定係 `desktop`，Android 機會 **hydration mismatch**。
   SSR／首次 render 一律唔出任何嘢。
6. **下載入口失敗一律靜默**：呢個係登入頁，拎唔到版本最多係少一個入口，
   絕對唔可以彈錯誤或者 throw 令整頁白屏。
7. 公開 API 加 `Cache-Control: public, s-maxage=60`（本專案對 egress／invocation 敏感）
   ⇒ 換版本後**最多 60 秒**生效（admin 頁有寫明）。
