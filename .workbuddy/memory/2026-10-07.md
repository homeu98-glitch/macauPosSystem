### 🔴 核心不變量（守衛測試守住）
1. **永不覆寫**：`baselinePatch` 只喺 `hit.baseline_unit_cost === null` 時先有值。
   ⚠️ 唔可以因為「搵到更早日期」就改寫 —— 舊收據可能被刪／補登，令**已報告咗嘅上漲金額自己郁**。
2. **duplicate-key 補插路徑**（`ilike`）用 `hasBase` 守住，唔可以漏。
3. **冇基準 ⇒ `changeAmount: null`（唔係 0）**，`direction: "new"`，`isComparable("new") === false`。
   當 0 會令「漲價影響金額」合計細咗、睇落好似真係零影響。
4. **基準 ≤ 0 或 null ⇒ 當 new**，唔會出 `Infinity`／`NaN`。
5. **漲／跌金額分開加**（`totalUpAmount` / `totalDownAmount`），唔可以淨計 `Σ(changeAmount)`
   —— 咁漲跌互相抵消，睇唔出真實影響。
6. `unit_price <= 0` 唔做基準。
7. 同日多筆 → 揀**單價較低**者（保守，令漲幅偏細，唔會誇大呃老闆加價）。
