## Sunmi 當 macau-pos 打印機（調研，未動 code）

用戶想將 Sunmi V2S（跑 `C:\dev\macau-ledger-merchant` APK）直接當 macau-pos 打印機，憂心紙張唔係 80/58mm 令 template 報廢。

**結論：功能早已存在，零 code 改動，只需兩邊設定。**
- APK v1.1.8 起內建「堂食 POS 打印中繼」（現 v1.1.20）：設定 → 堂食 POS 卡 → 開「啟用堂食 POS」→ 自動配對（merchantId 做 storeId）→ 卡片顯示本機 IP。
- macau-pos：打印中心加 LAN 打印機（IP = Sunmi **自己**嘅 IP、port 9100、paperSize=58mm）→ APK claim → `PosPrintDispatcher` 發現目標 IP == 本機 IP → 改打內置（AIDL sendRAWData）；其他 IP 先 TCP :9100。
- **V2S 官方規格就係 58mm**（支持寬度 58mm、外徑 40mm 紙卷、可印 48mm ≈ 384 dots）；用戶疑慮來自 57mm 紙卷標示。Template 全店共用、紙闊逐機設定；58mm → 32 欄/行（`EscPosRenderer.paperColumns()`／POS `paper-columns.ts`）。
- 未寫 printer jsonb 快照嗰條路：sync route 唔寫 `printer` 欄，APK 靠 `device-config`（5 分鐘刷新）嘅 printer_id 匹配拎 paperSize，最後 fallback `SUNMI_FALLBACK(58mm)`。
- 關鍵檔案：`posrelay/{PosJobRunner,PosPrintDispatcher,EscPosRenderer,LocalIpv4}.kt`；POS `print-bridge/dispatch.ts`（通道③ relay）、`relay-transport.ts`（只 flush sync queue 唔開 socket）、`api/pos/print-agent/*`；文檔 `docs/96`、`macau-ledger-merchant/docs/POS_RELAY.md`。
- 坑：一定要填 Sunmi 自己 IP（假 IP 唔 fallback）；DHCP 換 IP 要改綁定；需聯網；綠燈≠在線。唯一可能要動 code 嘅情況：部機真係其他型號＋紙寬唔屬 58/80/62mm（要先確認機型/紙卷）。

## Sunmi 測試印「顯示成功但無紙」排查（已改 code，待 rebuild）

用戶報：APK 設定頁堂食 POS 卡顯示「成功/運行中」，但撳「堂食測試印」無紙。

**根因**：
- 卡片那行「狀態：…」係 **relay（Realtime 通道）狀態**，唔係 Sunmi 打印機本體連接狀態。`AppState.printerStatus`（未連接/已連接/綁定失敗（非商米設備?））一直冇顯喺呢張卡。
- 「堂食測試印」→ `vm.testPosPrint` → `ACTION_POS_TEST_PRINT` → `PosRelaySession.printTestTicket()` → `sunmi.sendRaw()`。當 `service == null`（打印機未綁上）`sendRaw` 靜默回 false，只寫隱藏 relay log「堂食測試印失敗」，按鈕冇任何提示 ⇒ 用戶只見到 relay「成功」。
- 注意：`sendRAWData` 喺 Sunmi 缺紙/機蓋開時都可能回成功而無紙（硬件層常見）。

**真實訂單路徑安全**：`PosJobRunner` 第 207-220 行，`dispatchPrint` 回 false 會 `rollbackPendingPrint` + 上報 `failed`，唔會當已打印，下次對賬重投。

**改動（3 個 .kt，未 build）**：
1. `posrelay/PosRelayState.kt`：加 `testResult` StateFlow + `setTestResult()`。
2. `posrelay/PosRelaySession.kt` `printTestTicket()`：未連（`!sunmi.isReady()`）先 `sunmi.connect()` 再報「未連接，正在重連」；否則按 `sendRaw` 結果報「已送出 ✅ / 失敗 ❌」。
3. `ui/settings/SettingsScreen.kt` `DineInPosCard`：加 `printerStatus`、`testResult` 兩行（綠=正常、紅=異常），頂層 composable `collectAsStateWithLifecycle` 收 `PosRelayState.testResult`。
- 待用戶 rebuild APK（建議 v1.1.21）裝去 Sunmi 重測：卡上「打印機（內建）：」綠=已連接（再查紙張/機蓋）；紅=未連接（按鈕會自動重連＋顯「正在重連」）。
