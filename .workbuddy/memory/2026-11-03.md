## Vercel 流量爆沖 + 早上大量 error（診斷，未改碼）

用戶貼 Vercel Fast Data Transfer 圖：2.47 GB / 100 GB（**只 2.5%，冇用完**），但 11-02 單日有 ~1.2 GB 尖峰；
Incoming 1.97 GB（67%）> Outgoing 839.8 MB。

### 已查清（有證據）
- **APK 下載唔燒 Vercel 流量**：`src/app/api/download/apk/route.ts` 係 302 去 Supabase signed URL
  （`public/install.html` 亦零 `_next` 引用）⇒ 5.3 MB × N 次都唔計 Vercel FDT。
- Vercel 官方口徑：Incoming = **request**（含 header/body），Outgoing = response。所以爆嘅一定係「client 上傳」或「請求次數」。
- `[egress] pos/state bytes=435992 mode=full printJobs=200 src=mount` —— 每次 mount 全量 436 KB；
  若 30 秒一次 reload/mount ⇒ **1.25 GB/日**，同尖峰數字吻合（待 Observability 確認）。
- **device-token 死迴圈（真 bug）**：`[pos/device-token] 讀取 merchant_staff 失敗: JWT expired` 每 ~30 秒一次、多部機。
  `prepareLedgerServerClient()`（`src/lib/ledger/supabase-server-auth.ts`）用**舊 accessToken** 建 client 並釘死在
  `global.headers.Authorization`；`setSession()` 刷新後**冇用新 token 重建 client** ⇒ `auth.getUser()` 過到、
  PostgREST 仍然用過期 JWT。且 route 回 **503**（唔係 401）⇒ client 當「暫時性」無限重試。
  client 側 `refreshPosDeviceTokenIfNeeded()`（`pos-sync-auth.ts`）失敗後 0ms 清 inflight、無退避、無「請重新登入」⇒ 火燒連環船。
- 另一組：同一 store `8291f843…` 不斷打 `/api/pos/adopted-online-ids`、`/api/online-order-settings`、`pos/state` 全部 401 拒絕。
- 11-01 之後只有一個 commit（APK 短鏈 + install.html），冇改任何輪詢邏輯 ⇒ 尖峰唔係新 code 造成，係裝置行為。

### 第二個修復：POS 憑證續期（commit 30f2776）

三處缺陷：
1. `ledger-session-decision.ts` —— 開頁時 client 未有 session（`persistSession:false` 必然）**一律 bootstrap**
   ⇒ 拿已過期票去 `setSession()` 必敗。改：已過期／快過期 ⇒ `refresh`。
2. `supabase-server-auth.ts` —— `createLedgerServerClient()` 把 `Authorization` 釘死喺 `global.headers`，
   `setSession()` 更新 `client.auth` 但**唔改 header** ⇒ `merchant_staff` 永遠帶過期票。改：換票後重建 client。
3. `device-token/route.ts` —— 一律回 503（可重試語意）⇒ 無限重試。改：JWT 類錯誤回 **401 + code=session_expired**。
client：`refreshPosDeviceTokenIfNeeded()` 先 `ensureLedgerSession()`；401 落閂 10 分鐘（比對 storage token，
重新登入自動解閂）＋新 `PosAuthExpiredBanner`（in-flow、唔自動 reload）。
新檔：`src/lib/pos/auth-expired.ts`（零 import store）、`src/components/pos-auth-expired-banner.tsx`、
`src/app/api/pos/device-token/device-token-contract.test.ts`（9 項）。
