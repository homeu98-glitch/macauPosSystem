# 澳门 POS 系统总览

## 目标

当前版本面向饮品店、快餐店与轻堂食场景，覆盖一线门店日常最常用的收银流程：

- 堂食点单、加菜、结账、完成
- 快餐点单、收银、出单、取餐完成
- 线上订单接单、取消、制作中、完成
- 打印机、打印分区、收据机、标签机配置
- 常用备注、规格模板、菜品打印分区维护

## 页面结构

- `/`
  - 主收银台
  - 支持堂食 / 快餐两种工作模式
- `/settings`
  - 设备、打印机、菜品打印、菜单、桌台、支付方式、线上订单参数、备注
- `/orders`
  - 线上订单专页
- `/prints`
  - 打印中心
- `/soldout`
  - 沽清管理
- `/members`
  - 会员余额与优惠券
- `/shift`
  - 班次交接
- `/reports`
  - 报表看板

## 核心数据

### 本地缓存

当前主要使用 `localStorage` 做本地缓存与断网续传：

- `macau-pos/bootstrap`
- `macau-pos/device-config`
- `macau-pos/local-settings`
- `macau-pos/orders`
- `macau-pos/print-jobs`
- `macau-pos/sync-queue`
- `macau-pos/members`

### 关键业务对象

- `PosBootstrap`
  - 店铺、菜单、桌台、规则、打印分区
- `PosLocalSettings`
  - 本地支付方式、打印分区、菜品分区覆盖、常用备注、规格模板、线上订单开关
- `PosOrder`
  - 堂食 / 快餐订单
- `PrintJob`
  - 厨房单、收据、标签打印任务
- `QueueEvent`
  - 离线事件队列

## 打印模型

当前打印配置分为三类角色：

- `zone`
  - 分区出单打印机，例如厨房、水吧、甜品
- `receipt`
  - 收据打印机，默认一台收银台只指定一台
- `label`
  - 标签打印机，可按分区挂接

菜品不再直接绑定某一台打印机，而是先绑定到打印分区，再由对应打印机接收。这样换打印机时不用逐个改菜品。

## 当前推荐业务流程

### 快餐

1. 商家点餐
2. 自动切到收银区
3. 结账完成后再正式下单
4. 自动打印收据
5. 订单进入“待取餐 / 待交付”
6. 商家做完后标记“已完成”

### 堂食

1. 选择桌台
2. 点单并下单
3. 加菜或改单
4. 结账
5. 做完或离台后完成订单

### 线上订单

- 堂食线上单：接单后先安排桌台，再转入堂食订单
- 自取 / 自送 / 车手单：右侧卡片可直接接单、取消、完成

## 当前已知边界

- 蓝牙打印尚未接入
- 真正的打印驱动层仍需对接本地服务或网口打印适配层
- 线上订单字段仍依赖主系统表结构
- 规格模板现为本地设置能力，适合门店维护，不是总部模板中心
