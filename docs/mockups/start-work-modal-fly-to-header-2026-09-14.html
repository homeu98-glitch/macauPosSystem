⑦ 顯示／閘門邏輯、實作落點、剩低要確認嘅位
全部判斷共用現有 shift.openedAt（今日班次是否已開）—— 唔新增「營業中／未營業」等新概念，所以其他功能零影響。
一、顯示邏輯（真值表）
今日班次狀態彈窗頁首「開工」落單
openedAt == null彈（✕＋開工） 顯示（橙色＋光環）禁止（撳枱即提示）
openedAt == null（撳咗 ✕）收起 顯示仍然禁止 ＋ 常駐提示條
openedAt 有值（已開工）唔彈 自動隱藏正常
已交班（openedAt 清空）再次彈 再次顯示再次禁止
最後一行＝你講嘅情境：closeShift()（shift-page.tsx:734）交班時會將 openedAt 設為 undefined ⇒ 打烊後返嚟，彈窗必定再現（而家仲係關唔到）。加咗 ✕ ＋動畫之後，就可以「睇完數先決定開唔開工」。

  setToast({ tone: "info", message: "今日未開工，請先按頁首「開工」。" });

}
