  • 掃碼點餐模式（全店一碼 / 每枱一碼）目前係跟「登入模式」自動寫入。登入頁冇咗模式選擇之後，建議改為跟 ② 所選嘅工作台寫入：堂食收銀台 → 每枱一碼；快餐收銀台 → 全店一碼。

  • 如果商戶同時開通「堂食」同「快餐」兩個工作台，就要決定「邊一步寫入掃碼模式」（建議：揀完工作台即刻寫）。
