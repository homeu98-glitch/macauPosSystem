查咗程式碼：而家係「唔記得」——每次開頁（甚至 reload）都要重新撳「係，我是會員」＋入電話＋PIN。
現狀證據（use-kiosk-order.ts）
· :73-81 OrderingMember 只喺記憶體；§7.2 禁寫 localStorage（displayName／餘額／電話）
· :393-397 會員 state 唔入任何 storage，刻意唔因 reload 復原（Kiosk 共用平板要徹底清）
· :104-110 顧客 token 只准記憶體
· 得 sessionStorage kiosk-started／kiosk-last-order 係持久，但係「落單旗標／取餐號」，唔係身份
要「記得」就要起呢啲
設備記憶票：server 簽一個唔透明 token（綁 customerId＋設備＋到期），下次開頁帶 token 換返 displayName／餘額 ⇒ 畫面變「歡迎返嚟」（④ 號版面）。
只記身份、唔記錢包：免 PIN 窗口得 180 秒 ⇒ 隔咗一晚一定冇 ⇒ 扣款時仍然要入 PIN，或揀「到前台支付」。
出口：一定要有「唔係我／登出」（清 token）＋到期（建議 30 日）。
Kiosk 維持唔記：共用平板，而家行為正確，唔好改。
紅線（唔可以越）
記憶票／localStorage 只准存 token 或 customerId（uuid） —— 電話號碼一律唔落機。
displayName／餘額只作當次渲染，唔好自己 cache 落機（要就每次由 server 換）。
結論：你講嘅「第二次唔使再揀」係合理嘅，但今日未做到，要起記憶票先得。未起之前，④ 號版面只係設計稿。
