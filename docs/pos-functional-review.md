# 当前 POS 功能审查

## 结论

按门店日常使用标准看，这个版本已经能覆盖“饮品店 / 快餐店 / 轻堂食”的大部分高频工作，但距离完全稳定上线，仍有几项建议在下一轮继续补齐。

## 目前已可满足的日常工作

### 点单与收银

- 堂食点单、加菜、改单、结账
- 快餐点单、结账后下单、完成出餐
- 会员余额与优惠券抵扣
- 全单备注与单品备注
- 菜品规格选择

### 打印

- 分区出单
- 收据打印
- 标签打印机配置
- 打印中心查看与重打

### 线上订单

- 新单提示
- 接单 / 取消
- 堂食单安排桌台
- 自取 / 自送 / 车手单制作完成

### 设置维护

- 打印分区
- 菜品打印分区
- 菜单维护
- 规格模板
- 常用备注
- 支付方式
- 自动接单

## 还建议补的能力

### 高优先级

- 退款 / 退菜 / 取消结账
- 日结与交班核对
- 厨房单与收据模板预览
- 标签打印内容模板
- 线上订单更细的状态追踪，例如“待取餐”“配送中”

### 中优先级

- 分类、菜品、模板的搜索
- 批量编辑菜品价格
- 报表按日 / 班次筛选
- 更细的权限与员工账号

### 稳定性建议

- 把 `localStorage` 队列迁移到 `IndexedDB`
- 引入错误边界与页面级 fallback
- 对打印桥接服务做心跳检测
- 对主系统接口增加版本号或 `updated_at` 增量同步

## 适配门店类型判断

### 已较适合

- 奶茶店
- 咖啡店
- 炸鸡 / 小食 / 轻快餐
- 有少量堂食桌台的饮品店

### 仍需谨慎

- 大型中餐酒楼
- 多厨房复杂联动餐厅
- 对后厨工位分单要求非常细的门店
- 强依赖桌边结账与服务员 PDA 的场景

## 本轮优化摘要

本轮已经补齐或优化：

- 设置页滚动与可见性
- 菜品打印设置可操作性
- 规格模板复用
- 规格弹窗滚动
- 常用备注保存流程
- 快餐与线上订单流程一致性
- 中文化线上订单标签
- 文档补全

## 上线前建议做一次实店验收

建议用真实店员流程跑一次：

1. 快餐下单到收据打印
2. 堂食点单到桌台完成
3. 线上自取单接单到完成
4. 断网后下单与恢复网络补传
5. 厨房单、收据、标签三类打印联测

如果这 5 条都顺畅，当前版本已经可以进入门店试运营。
