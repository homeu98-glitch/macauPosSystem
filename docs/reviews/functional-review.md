# 功能成熟度審查

> **最後更新**：2026-08-12  
> 審查基準：飲品店 / 快餐店 / 輕堂食門店日常使用

---

## 結論

按門店日常使用標準，本版本已覆蓋大部分高頻工作，可進入**試運營**。距離完全穩定上線，仍有高優先項待補。

---

## 已可滿足的日常工作

### 點單與收銀

- 堂食點單、加菜、改單、結帳
- 快餐點單、結帳後下單、完成出餐
- 會員餘額與優惠券抵扣
- 全單備註與單品備註
- 菜品規格選擇

### 打印

- 分區出單
- 收據打印（任務隊列）
- 標籤打印機配置
- 打印中心查看與重打

### 線上訂單（Ledger）

- 新單提示音
- Realtime 接單 / 取消
- 堂食單安排桌台
- 自取 / 自送 / 車手單完成
- 扣點接單、到店付接單

### 設置維護

- 打印分區、菜品打印分區
- 菜單維護、規格模板、常用備註
- 支付方式、自動接單
- PWA 安裝

### 營運輔助

- 沽清管理
- 班次交接
- 報表摘要（Ledger）
- Admin / Backoffice（需 POS Supabase）

## 還建議補的能力

### 高優先

- 退款 / 退菜 / 取消結帳
- 日結與交班核對（班次有基礎，核對待強化）
- 廚房單與收據模板預覽
- 標籤打印內容模板
- 線上訂單更細狀態（待取餐、配送中）
- **真實 LAN/USB 打印驅動** — `print-bridge` 本機服務（見 `print-bridge/README.md`）

### 中優先

- 分類、菜品、模板搜索
- 批量改價
- 報表按日 / 班次篩選
- 更細權限與員工帳號

### 穩定性

- [ ] localStorage 隊列 → IndexedDB
- [x] 錯誤邊界（`app-error-boundary.tsx`）
- [ ] 打印橋接服務心跳
- [ ] bootstrap 增量同步（since_version）
- [ ] HiveMQ 接入（程式已寫未連）

## 適配門店類型

### 已較適合

- 奶茶店、咖啡店
- 炸雞 / 小食 / 輕快餐
- 少量堂食桌台的飲品店

### 仍需谨慎

- 大型中餐酒樓
- 多廚房複雜聯動
- 後廚工位細分要求極高
- 強依賴桌邊結帳 / 服務員 PDA

## 上線前實店驗收清單

用真實店員流程跑一遍：

1. [ ] 快餐下單 → 收據打印（或打印中心預覽）
2. [ ] 堂食點單 → 桌台 → 結帳 → 完成
3. [ ] 線上自取單：Ledger 下單 → POS 接單 → 完成
4. [ ] 斷網下單 → 恢復網絡 → sync 補傳
5. [ ] 廚房單、收據、標籤三類打印聯測（需橋接服務）

五項順暢 → 可試運營。
